مستودع للنشر فقط. يحوي التقرير المُصدَّر كملف واحد قائم بذاته لا غير.

**الرابط:** يُفتح عبر GitHub Pages بعد تفعيلها (الإعداد أدناه).

## ⚠️ قبل أي إضافة

الموقع المنشور عبر GitHub Pages **عام لأي أحد على الإنترنت** على الخطط
غير Enterprise. فكل ما يوضع هنا يُعتبر منشورًا علنًا.

**لا تضع هنا أبدًا:**

- `.env` أو أي توكن — صلاحية كاملة على حساباتك الإعلانية
- كشف المتجر (`*.xlsx`) أو `margins.json` — تكلفة وهامش كل منتج
- `store_sales.json` — مبيعات المتجر الحقيقية
- ملفات `zid_exports/` — أسماء العملاء وهواتفهم

`.gitignore` يحجب هذي كلها احتياطًا، لكن الحاجز الحقيقي هو الانتباه.

⚠️ وتذكّر: ما يُرفع مرة يبقى في **تاريخ Git** حتى بعد حذفه. الحذف لا يكفي —
يلزم إعادة كتابة التاريخ أو حذف المستودع كاملًا.

## الصفحات

المنصات، ورفع `index.html` وحدها يعطي `ERR_FILE_NOT_FOUND` عند أول نقرة
على اسم منصة.

## تحديث التقرير

بعد كل تحليل جديد في مجلد المشروع:

```powershell
cd C:\Users\hp\google-ads-automation
python export_html.py --share

copy share\*.html C:\Users\hp\rexo-reports\

cd C:\Users\hp\rexo-reports
git add -A
git commit -m "تقرير محدّث"
git push
```

`--share` يولّد نسخة النشر: بلا REXO Chat وبلا أرقام الحسابات، وبأسماء
ملفات صالحة للويب. لا تنسخ `analysis_report.html` مباشرةً — تلك نسختك
الخاصة وفيها المساعد الذي يطلب مفتاح API.

الرابط نفسه يتحدّث خلال دقيقة تقريبًا.
